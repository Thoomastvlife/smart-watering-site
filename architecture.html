🌱 讓綠意蔓延吧動機與創意七項功能軟硬體架構實機與介面實測紀錄作品優勢結論與參考團隊

軟硬體架構

硬體元件用途
ESP32 控制板系統核心，負責控制所有元件與網路連線
步進馬達與驅動器帶動滑塊在軌道上移動
紅外線感測器 ×3偵測滑塊是否到達指定位置
土壤濕度感測器 ×3偵測三盆植物的土壤濕度
水泵負責澆水
繼電器控制水泵開關
電源供應器提供系統電力
軟體工具用途
Arduino IDE撰寫與上傳程式碼
網頁伺服器內建於 ESP32，提供網頁介面
HTML / CSS / JavaScript設計網頁介面
ntfy 推播服務發送通知到手機
Blynk 手機儀表板在手機上查看濕度、位置並開關控制
網路時間同步（NTP）取得正確時間顯示於網頁

網路技術

WiFi 連線

ESP32 連線至區域網路。

網頁伺服器

提供遠端監控與控制介面。

推播服務

主動發送通知到手機。
