軟硬體架構

ESP32 作為控制核心，整合感測、移動、供水與網路功能。

系統架構

模組負責的事
土壤濕度感測器 ×3讀取各盆土壤濕度
紅外線感測器 ×3回報位置訊號
ESP32資料判斷、流程控制、網頁伺服器、Wi-Fi
步進馬達＋皮帶滑軌移動出水口
繼電器＋水泵控制出水

Wi-Fi 網路連線提供手機與電腦的網頁監控，並透過 ntfy 服務發送推播通知。

硬體元件

元件用途
ESP32 控制板系統核心，負責控制所有元件與網路連線
步進馬達與驅動器帶動滑塊在軌道上移動
紅外線感測器 ×3偵測滑塊是否到達指定位置
土壤濕度感測器 ×3偵測三盆植物的土壤濕度
水泵負責澆水
繼電器控制水泵開關
電源供應器提供系統電力

軟體與網路技術

工具用途
Arduino IDE撰寫程式並上傳至 ESP32
HTML / CSS / JavaScript設計手機與電腦可使用的網頁操作介面
ESP32 網頁伺服器提供即時狀態查詢與手動控制功能
Wi-Fi 連線讓 ESP32 與使用者裝置透過網路交換資訊，並以 NTP 同步時間
ntfy 推播服務定時回報狀態，並在澆水或異常時通知使用者
Blynk 手機儀表板提供手機端儀表板，遠端查看狀態與操作
